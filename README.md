# Ship Design and Operation Lab, NTNU

**Portfolio page: https://shiplab.github.io/portfolio/**

Open tools and data for early-stage ship design, made for teaching and research.

## Tools and data

| | | |
| --- | --- | --- |
| [Ship Design Building Block Editor](https://shiplab.github.io/dbb/) | Arrange the spaces of a ship as 3D blocks; weights, floating and stability | [code](https://github.com/shiplab/dbb) |
| [Hull Generator](https://shiplab.github.io/hull/) | Make and reshape a hull form; hydrostatics, Holtrop resistance, table of offsets | [code](https://github.com/shiplab/hull) |
| [Ship Evacuation](https://shiplab.github.io/evac/) | Persons walking to the muster stations of a Building Block Editor layout | [code](https://github.com/shiplab/evac) |
| [R/V Gunnerus Open Data Set](https://shiplab.github.io/gunnerus/) | Drawings, 3D model, documents and operational data for R/V Gunnerus | [repository](https://github.com/shiplab/gunnerus) |

## Legacy

No longer maintained; kept online as a reference.

- [Vessel.js](https://github.com/shiplab/vesseljs) (2017–2025): JavaScript library for conceptual ship design.
- [dt_cv](https://github.com/shiplab/dt_cv) (2020–2026): digital twins of model ships.
- [openbridge](https://github.com/shiplab/openbridge) (2021–2023): Vessel.js with OpenBridge (AHO).

## Contributors

Over the years many students and colleagues, at NTNU and at partner universities, have contributed to these tools and data sets. Their names are in each repository.

## Disclaimer

The tools are for education and early concept work. Hulls are illustrative, and weights, hydrostatics, stability, resistance and evacuation times are simplified estimates. Do not use the results for design approval, class or flag-state documentation, or any safety-critical decision. The software and data are provided as they are, without warranty; each repository states its licence.
